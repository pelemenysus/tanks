# Танковая битва 3D

Браузерная 3D-игра про танки. Сотни машин (СССР, Германия, США, Британия), рельеф, системы брони/пробития, волны врагов, магазины, золото, рулетка и ежедневные награды.

## Запуск

Открыть `tanks3d.html` в браузере. Для сетевого боя — запустить `server.py` (порт 8765):

```bash
python3 server.py
```

## Файлы

- `index.html` — главная страница
- `tanks3d.html` — игра
- `three.min.js`, `GLTFLoader.js` — Three.js r128 (локально, офлайн)
- `models/` — 3D-модели танков (309 файлов, GLB)
- `server.py` — сервер сетевого боя (asyncio WebSocket, без зависимостей)
